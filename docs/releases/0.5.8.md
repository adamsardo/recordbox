# Recordbox 0.5.8

## STEMS on Windows Radeon

- Run `recordbox.exe --stems-status` to see the build, Radeon driver, dedicated and shared memory figures, runtime files and local model file sizes. This report works before opening a library or starting GPU inference.
- When DirectML is paused, the deck and Preferences offer **Separate on CPU** for one loaded track. The progress display identifies the wait for the first segment. A manual retry honors the failed track's model, and the deck tooltip follows the running job if you change models in Preferences.
- Recordbox now replaces truncated model downloads after checking the replacement's size and checksum. A partial checkpoint could previously send the deck into a download loop.
- DirectML uses the smaller, staged inference path when Windows cannot identify an adapter's memory architecture. The guard for the previously affected Vega 8 driver remains in place.
- On a physical Vega 8 using Windows driver 31.0.21925.1001, the compute check passed and the speed model reached 85% on a 6:18 track. Completion and fine-tuned model results on that adapter are still unconfirmed.

## Packaging and dependencies

- A publishing retry verifies an existing public release against the tagged build. It succeeds when the release metadata and assets match.
- Updated the Rust `url` dependency to 2.5.9 for RUSTSEC-2026-0592. The release workflow also checks the repository's existing advisory baseline.
