# Recordbox 0.6.0

## Desktop library sync

The circular arrows at the bottom of the library sidebar open a review. Check the detected rekordbox desktop database and the path of the active Recordbox library before starting the import. The same review is available from the File menu. Recordbox reads a private copy of the source database and its write-ahead log. It may read locally accessible audio to fill missing metadata. Confirming the import can update tracks, cues and the mirrored playlist tree in Recordbox.

The destination merge now rolls back when a database write fails. A missing pair of optional history tables is supported. An unreadable or incomplete history schema stops the import before it can replace the destination mirror.

Automatic import at startup requires a fresh opt-in in Preferences, including after an upgrade. If you want to test first, leave it off and open the review. Device Sync Manager is a separate operation for USB devices. [Sync behavior, local edits and supported library formats](https://github.com/fantuz/recordbox/blob/v0.6.0/docs/LIBRARY-SYNC.md)

## Experimental Vulkan STEMS on Linux x64

The Linux Vulkan archive adds a hybrid backend for HTDemucs. The GPU runs the transformer linear layers and the CPU handles the remaining model operations. Use `./recordbox --stems-status` to inspect the adapter without running inference. Use `./recordbox --stems-device` for a small compute test. On the deck, choose **STEMS → Separate** to begin.

Work is submitted in bounded batches. A timeout, device loss or invalid result pauses Vulkan for the rest of the session. **Retry CPU** repeats the track with the same model. To compare the actual sound and speed on your hardware, run `./recordbox --compare-stems "/path/to/clip.wav"` with the speed-model checkpoint installed.

All five HTDemucs checkpoints passed comparisons against CPU using Mesa software Vulkan. The largest observed difference across the synthetic test clips was 0.002% relative RMS. Physical Vega 8 performance and driver stability on Linux still need hardware validation. [Linux Vulkan guide](https://github.com/fantuz/recordbox/blob/v0.6.0/docs/VULKAN.md)
