# Recordbox 0.5.6

## Radeon STEMS preview for Windows

- Choose the new Windows x64 DirectML ZIP to try STEMS separation on a Radeon Vega 8 or another AMD GPU with a DirectX 12 driver. The ZIP includes the Microsoft inference libraries.
- Run `recordbox --stems-device` to check the selected adapter and `recordbox --compare-stems FILE` to compare four stems and elapsed time against the CPU. The speedup and shared-memory requirements depend on the adapter and track. [Radeon setup and comparison guide](https://github.com/fantuz/recordbox/blob/v0.5.6/docs/DIRECTML.md)
- The standard Windows x64 ZIP is listed as supported. Linux x64 keeps its experimental designation. Both CUDA 12 previews and both macOS packages remain available.
