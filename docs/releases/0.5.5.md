# Recordbox 0.5.5

Prepared 2026-11-20 (Europe/Zurich).

## Optional NVIDIA STEMS acceleration

- Windows and Linux x64 now have separate **CUDA 12 STEMS preview** downloads. The first hardware target is the Quadro P2000. Install CUDA 12.9 runtime libraries and an NVIDIA driver that supports CUDA 12.9 PTX. The four standard packages are also available.
- **Preferences → Extensions → STEMS** shows the selected backend. The CUDA build checks a floating-point convolution and matrix multiplication before displaying the adapter, compute capability and video memory. Attention is computed in blocks to reduce temporary GPU memory use.
- Run `recordbox --stems-device` to see the selected backend or launch with `--stems-cpu` to use the CPU for that session. Windows now reports installed system RAM when assessing model availability.
- Run `recordbox --compare-stems FILE` to compare uncached, four-stem GPU and CPU separation on one local song using the same downloaded HTDemucs checkpoint. It reports timing and numerical agreement. Actual throughput and memory fit on a physical P2000 still need a hardware run. [Windows and Linux setup and comparison guide](https://github.com/fantuz/recordbox/blob/v0.5.5/docs/CUDA12.md)
