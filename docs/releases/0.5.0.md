# Recordbox 0.5.0

First packaged release from the `fantuz/recordbox` fork. It includes the current
desktop DJ library, track analysis, waveforms, cues, playlists and
Pioneer-compatible USB export. This release focuses on dependency security,
backup integrity and verified distribution of that existing application.

## Changes

- Resolves six previously identified dependency alerts by upgrading ZIP to
  **9.7.1**, Candle to **0.11.1**, and removing Muda's unused GTK3/GLib backend.
  Custom Metal bindings use Candle's tracked input/output buffer API.
- Rejects inconsistent ZIP headers before reading backup manifests or changing
  restore directories. Regression coverage checks malformed manifest, database
  and artwork entries while preserving existing files.
- Adds native packages for macOS Apple Silicon, macOS Intel, Windows x64 and
  Linux x64. Archives include source/version metadata, runtime requirements,
  file hashes and licenses. CI artifacts also include SHA-256 sidecars. Personal libraries, audio,
  credentials and model downloads are excluded.
- Runs **85 packaging and release-tooling regression tests**, full application-suite reporting,
  native backup regressions, dependency-advisory gates and isolated screenshot
  smoke checks. New failures and changed/stale baselines block publication.
- Pins build tooling and native dependencies; reuses platform/architecture Rust
  caches and the Windows OpenSSL cache, preserves Rust caches on failure, and
  saves OpenSSL before later build steps. Windows Rust cache reuse still depends
  on the runner's installed toolchain set.
- Publishes this fork's release from a matching version tag only after that
  revision passes its integrity gates and its notes, archives, smoke evidence
  and checksums agree. Uploaded draft assets are verified before publication.

## Known limitations

- Packages are **unsigned and not notarized**. Windows/Linux remain experimental:
  Finder, Apple Music, Audio MIDI Setup and device-eject integrations are
  macOS-specific; USB autodiscovery, native menus/shortcuts, Windows memory
  reporting and Metal acceleration retain their existing platform limitations.
- GUI smoke verifies startup and rendering using synthetic data. Windows CI uses
  two temporary, pinned Mesa software-renderer DLLs; they are **not included in
  the product ZIP**. These checks do not prove physical audio playback, USB
  hardware operation or Metal GPU computation.
- One existing PDB-export test still fails with subtraction overflow:
  `export::usb_fix_test::a1_a_row_too_big_for_a_page_is_an_error_not_a_panic`.
  The application baseline is **235 passed, 1 tracked failure, 25 ignored**;
  formatting and Clippy warnings remain visible in reports.
- Three existing dependency advisories remain unresolved:
  `libsqlite3-sys 0.38.2` (**RUSTSEC-2026-0459**) and transitive `quick-xml 0.30.0`
  (**RUSTSEC-2026-0194**, **RUSTSEC-2026-0195**). The exact baseline is disclosed
  and enforced; this release does not claim a clean security audit.
