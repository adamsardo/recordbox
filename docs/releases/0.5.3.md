# Recordbox 0.5.3

Prepared 2026-11-20 (Europe/Zurich).

Recordbox 0.5.3 helps recover missing tracks when a collection moves between computers. For example, on Linux or macOS, a track saved as `D:\Sets\Café Mix.wav` can now be found by searching the folder that contains `Café Mix.wav`.

## Recovering missing files

- Use **File → Relocate Missing Files…** to search a folder you choose, or **Auto Relocate** to search the folders in **Preferences → Advanced → Browse**. Both commands recognize filenames from Windows drives, Windows network shares and macOS or Linux paths.
- A track with a recorded file size is relinked when exactly one available candidate matches its filename and byte count. If the library has no recorded size, a single available same-named file can qualify. The summary distinguishes a size mismatch, several candidates, a file whose attributes could not be verified, and a path another track already uses.
- When two selected missing tracks point to the same replacement, both stay available for individual review. Use **Track → Relocate → Relocate** to choose a file yourself. Two different recordings can share a filename and size.
- A successful relocation updates only the path in Recordbox’s collection. The track keeps its ratings and cues, and the result is counted after the new path is saved. The search reads file attributes and leaves the audio in place.

## Validation and compatibility

- The Linux application suite for the recovery change passed 270 tests, with 36 marked as ignored. Fixtures cover Windows and macOS paths, Unicode filenames, conflicting sizes and two tracks competing for the same file in either search order. The packaging suite covers 107 tests.
- Native package checks cover startup and rendering on both Mac architectures, Windows x64 and Linux x64. Windows and Linux packages are experimental. All four packages are unsigned, and the macOS apps are unnotarized.
- Two advisories remain open for the transitive `quick-xml 0.30.0` dependency. CI checks against the recorded baseline on each release.
