# Recordbox 0.5.1

Maintenance release from the `fantuz/recordbox` fork, incorporating the ANLZ
import fixes and playback CPU improvements merged since 0.5.0.

## Changes

- Apply signed PQTZ header shifts when importing beatgrids, so deck-edited
  timestamps use their effective positions. Validate framing, counts, beats,
  tempo and ordering; preserve unchanged paired PQTZ/PQT2 sections.
- Decode plain and masked PSSI phrase versions 0 and 1 with the correct
  version-dependent mask and checks for entry size, count and mood. Reuse
  native phrases only when source beat indices still match the audible grid,
  preventing shifted grids from attaching phrases to the wrong positions.
  See [ANLZ import integrity](https://github.com/fantuz/recordbox/blob/v0.5.1/docs/ANLZ-IMPORT-INTEGRITY.md).
- Cache static waveform overview data per deck and use stack-based waveform
  layers in the overview, detail view and browser. Cache invalidation covers
  track/analysis replacement, resizing, display style and native waveform
  changes; playhead, progress shading, cues and animation remain live.
- Skip the settled unity-fade cosine in playback and reuse Gate Comp
  coefficients while their inputs stay unchanged. Moving fades, jump
  transitions and effect behavior retain their regression coverage.
- Add reproducible, synthetic playback and moving-waveform benchmarks. On the
  measured Intel Xeon, default one-deck 44.1-to-48 kHz callback elapsed time
  fell from **17.93 to 14.83 microseconds per 512-frame buffer**; default
  overview preparation plus mesh generation became **2.60 times faster**.
  These are component timings, excluding GPU, driver and whole-window CPU
  costs. See [Playback performance](https://github.com/fantuz/recordbox/blob/v0.5.1/docs/PLAYBACK-PERFORMANCE.md).
- Make release archive filenames, checksums and source history directly
  downloadable. The release generator refreshes links for every repository
  and version. README badges and its download button follow the latest stable
  release automatically.
- Retain **92 packaging/release-tooling tests**, add format/audio/cache
  regressions, and validate all four native packages and their source,
  checksums, licenses and synthetic GUI smoke evidence before publication.
- Use the macOS 26 runner for Apple Silicon packaging, retaining native
  architecture validation and smoke checks of the extracted application.

## Known limitations

- Packages are **unsigned and not notarized**. Windows and Linux remain
  experimental; native menus, USB/device discovery, Finder, Apple Music,
  Audio MIDI Setup and device-eject integrations retain their existing
  platform limitations. Metal acceleration remains macOS-specific.
- Grids with effective timestamps before zero remain unsupported for import.
  This release does not add PQT2 fractional timestamp import, a new native
  STEMS format or universal player/firmware compatibility. Unsupported raw
  sections retain the existing preservation behavior.
- Tests use generated data and stand-ins where hardware is required. GUI
  smoke does not establish physical audio playback, USB operation, graphics
  driver efficiency or Metal computation. Windows smoke uses temporary,
  pinned Mesa DLLs that are excluded from the product ZIP.
- The full serial application suite retains **251 passing tests, one tracked
  failure and 27 ignored tests**. The failure is the existing PDB-export
  subtraction overflow in
  `export::usb_fix_test::a1_a_row_too_big_for_a_page_is_an_error_not_a_panic`.
  Two ignored tests are the new opt-in CPU reports. Formatting and Clippy
  findings remain visible; the gate rejects new application failures.
- Three dependency advisories remain unresolved: `libsqlite3-sys 0.38.2`
  (**RUSTSEC-2026-0459**) and transitive `quick-xml 0.30.0`
  (**RUSTSEC-2026-0194**, **RUSTSEC-2026-0195**). The exact baseline is
  disclosed and enforced; this release does not claim a clean security audit.
