# Recordbox 0.8.0

## Use a second window for the library

In EXPORT or PERFORMANCE, click the overlapping-windows button at the right of the top bar to move the library browser into its own window. The decks stay in the main window. Your playlist, search, selection and scroll position follow the browser. Close the library window to put it back. To load a track from the detached library, select the destination player and double-click the track or press **Return**.

Each window can be resized or maximized independently. Move one window to a second monitor and press **F11** in either window to toggle fullscreen for both. **Space** plays or pauses the active deck in either mode and types a space when a text field has focus.

## Clear and replace hot cues

**Shift+1** through **Shift+8** clear hot cues A through H, including on keyboards that send punctuation for a shifted digit. Number-pad shortcuts also recognize shifted digits. Custom key assignments retain priority. To replace a cue, clear it, move the playhead, then press the plain number. **Edit → Undo** restores the previous edit.

A track’s first beat-grid analysis now respects a cue cleared while the job was running. Edits to a hot cue update every deck holding that track. Clearing a slot also removes duplicate entries for that slot in older libraries. If a cue edit, Undo or Redo fails during a database write, the saved cues and edit history remain available to retry.

The cue fix was exercised during CPU STEMS separation on Linux and verified after switching tracks and restarting Recordbox. Native keyboard tests covered US and Swiss German layouts and all eight keypad shortcuts. Interactive Windows and macOS testing remains open. The build guide lists tracked dependency advisories, lint findings and package requirements.
