# Recordbox 0.5.7

## Radeon STEMS recovery on Windows

- Opening Recordbox or its Preferences now reads the Radeon adapter name and defers the STEMS compute device until the first job or an explicit device check.
- On integrated Radeon adapters, deck separation, vocal detection and stem-assisted key analysis take turns on the GPU. HTDemucs uses smaller attention tiles, keeps fewer audio buffers in shared memory and releases the compiled model after each checkpoint.
- A failed DirectML job offers **Retry CPU** for the affected track. It uses the same downloaded model and keeps the configured GPU available for other tracks.
- Hover over a STEMS error to read it or click to copy it. DirectML errors identify the failing operation and report the driver’s device removal reason and memory budget when available.
